# Dataset attributions

SegreSmart is designed to consume user-downloaded copies of:

- Roboflow, “GARBAGE CLASSIFICATION 3”: https://universe.roboflow.com/material-identification/garbage-classification-3
- Roboflow, “Waste Classification 4Class”: https://universe.roboflow.com/swabdemo/waste-classification-4class
- Kaggle, “Waste Classification” by phenomsg: https://www.kaggle.com/datasets/phenomsg/waste-classification/data

Check the license and attribution text bundled with each downloaded version before redistribution. This repository does not redistribute dataset images and does not remove their original attribution or license files.
